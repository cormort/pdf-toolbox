PDF 頁面重組工具 - 專案文件

專案目的

此工具旨在解決使用者需要合併多個 PDF 檔案、重組頁面順序、並生成包含專業目錄的單一 PDF 檔案的需求。傳統方法通常需要使用昂貴的商業軟體且操作繁瑣，本工具透過瀏覽器客戶端技術，提供一個直觀、高效且無需安裝的解決方案。

主要功能

  • 多檔案上傳：支援透過拖曳或檔案選擇器一次上傳多個 PDF 檔案。
  • 頁面視覺化：以縮圖或清單模式預覽所有來源 PDF 的頁面。
  • 彈性頁面選取：支援單點選取、按住 Shift 鍵進行範圍選取。
  • 直觀排序：在「已選擇的頁面」面板中，透過拖曳自由調整頁面與章節的順序。
  • 章節分隔：可新增自訂標題的「小節」，讓產出的目錄更具結構性。
  • 目錄自動生成：可選擇在最終 PDF 的第一頁自動生成專業的目錄頁，包含頁碼對應。
  • 批次編輯目錄：提供文字編輯器，可一次性修改所有選定頁面在目錄中顯示的標題，行首每 2 個空白代表縮一層。
  • 讀取來源書籤：載入 PDF 時自動抽出來源檔既有的書籤（標題、階層、頁碼），可一鍵帶入目錄，省去手打。
  • 寫入 PDF 書籤：把最終目錄寫成 PDF 原生書籤大綱，在閱讀器左側的書籤面板可直接跳章節（可獨立於「目錄頁」開啟）。
  • 依小節拆成多檔：每個小節各輸出一個 PDF，下載時打包成 ZIP；檔名可用 {n}／{title} 等變數組成。
  • 一頁多張／騎馬釘：列印用拼版（2/4/6/9 up），騎馬釘會自動重排頁序，對折後頁碼連續。
  • 版面調整：可裁掉掃描件的多餘白邊、四邊內縮，或把混雜的頁面尺寸統一成 A4／A5。
  • 分節頁碼編號：有小節時頁碼會在每個小節重新起算，並可用 [roman-lower] 等行首標記讓該小節改用羅馬數字／中文數字／字母編號。
  • 頁面標記（頁首／頁尾／頁碼）：三者共用同一組變數與位置邏輯，可各自設定格式與位置。
  • 浮水印／印章：在成品頁面疊字（例如「機密」），可置中或平鋪，並可用頁面範圍指定只蓋某幾頁。
  • 復原／重做：所有編輯都能用 Ctrl+Z／Ctrl+Shift+Z（或工具列按鈕）復原，歷史深度 60 步。
  • 工作階段還原：載入的檔案與編排會自動存在瀏覽器（IndexedDB），重新開啟時可選擇還原。
  • 來源頁面管理：提供刪除模式，可從來源面板中移除不需要的頁面。
  • 純客戶端運作：所有操作均在使用者瀏覽器中完成，確保檔案的隱私與安全，無需上傳至伺服器。
  • 保留文字內容：生成的 PDF 保留原始文字，支援搜尋與複製。
  • 中文字型支援：內嵌「思源黑體」字型，確保目錄中的中文能正確顯示。

技術棧

  • 前端框架：原生 HTML, CSS, JavaScript，無任何外部框架，確保輕量與高效。
  • PDF 渲染：使用 Mozilla 的 pdf.js 函式庫，負責讀取 PDF 檔案並將頁面渲染成 Canvas 圖像以供預覽。
  • PDF 生成與編輯：使用 pdf-lib.js 函式庫，負責建立新的 PDF 文件、複製來源頁面、新增目錄頁與頁碼等核心功能。
  • 字型處理：使用 fontkit，配合 pdf-lib.js 來註冊並嵌入自訂的 OTF/TTF 字型檔。
  • PDF 加密： 原使用 pdf-encryptor 函式庫提供 AES-256 加密功能，已根據需求移除。

專案結構

要運行此專案，您需要以下檔案結構：

/
|-- index.html            (主 HTML 檔案)
|-- instruction.html      (本文件頁)
|-- style.css             (CSS 樣式表)
|-- script.js             (主要的 JavaScript 邏輯)
|-- verify.mjs            (端到端驗證：node verify.mjs)
|-- README.md
|-- fonts/
|   └─ NotoSansTC-Regular.ttf  (思源黑體，用於目錄與頁碼)
|-- pdf.min.js            (pdf.js 主檔案)
|-- pdf.worker.min.js     (pdf.js 的 Web Worker)
|-- pdf-lib.min.js        (PDF 生成與編輯)
|-- fontkit.umd.min.js    (字型子集化，供 pdf-lib 嵌入中文)
|-- sortable.min.js       (拖曳排序)
└─ examples/              (沒有內建；測試檔由 verify.mjs 即時產生)

操作指南

請依照以下步驟使用本工具，整個過程非常簡單直觀。

  1. 第一步：載入 PDF 檔案

    您可以透過兩種方式載入檔案：

    • 拖曳檔案：直接將一個或多個 PDF 檔案從您的電腦桌面或資料夾拖曳到左側標示有「📁 拖曳 PDF 檔案到這裡」的虛線框內。
    • 點擊按鈕：點擊「選擇檔案」按鈕，然後在跳出的視窗中選擇您想要處理的 PDF 檔案。

    載入的檔案會顯示在「已載入檔案」清單中，同時其所有頁面會顯示在右側的「原始 PDF 頁面」面板中。

  2. 第二步：選擇需要的頁面

    在「原始 PDF 頁面」面板中，您可以選擇要包含在新 PDF 中的頁面：

    • 單擊：點擊任何一個頁面縮圖即可選取它。已選取的頁面會出現綠色邊框。
    • 再次單擊：再次點擊已選取的頁面可以取消選取。
    • 範圍選取：先點擊一個頁面，然後按住鍵盤上的 Shift 鍵，再點擊另一個頁面，可以一次選取這兩個頁面之間的所有頁面。

    所有被選取的頁面會按照您點選的順序，出現在下方的「已選擇的頁面」面板中。

  3. 第三步：整理與排序頁面

    在「已選擇的頁面」面板中，您可以對頁面進行最終的整理：

    • 拖曳排序：按住任何頁面左側的「⋮⋮」圖示，然後上下拖曳即可改變其順序。
    • 新增小節：點擊「➕ 新增小節」按鈕，輸入小節標題（例如：「第一章 合併資產負債表」），這會在目錄中建立一個章節標題，讓結構更清晰。小節本身也可以被拖曳排序。
    • 批次編輯目錄標題：點擊「✏️ 批次編輯目錄」按鈕，會彈出一個文字編輯器。您可以一次性修改所有頁面在目錄中顯示的標題，每一行對應一個頁面；行首每 2 個空白代表縮一層（同時決定目錄頁縮排與書籤階層）。
    • 帶入來源書籤：在同一個編輯器裡按「🔖 帶入來源書籤」，會用來源 PDF 既有書籤的標題與階層覆蓋目前的目錄內容。來源沒有書籤時會提示並保留原標題。
    • 移除頁面：點擊任一頁面右側的「✕」按鈕，可以將其從選取清單中移除。

  4. 第四步：生成最終的 PDF

    完成所有整理後，點擊左下角的綠色按鈕「生成新的 PDF」。

    • 新增目錄頁：勾選「新增目錄頁」後，生成的 PDF 第一頁（跨頁時為前幾頁）會有目錄與可點擊的頁碼連結；勾選「新增頁碼」則會在每一頁印上頁碼。
    • 頁面標記：勾選「#️⃣ 頁面標記（頁首／頁尾／頁碼）」後展開設定。三者共用變數：{n} 頁碼、{total} 總頁數（含目錄頁）、{name} 檔名、{date} 日期。頁首與頁尾留空就不印（頁碼留空會退回純數字）；位置各自獨立選擇，邊距與字級三者共用，另有四個頁碼快速套用格式。
    • 浮水印／印章：勾選「💧 浮水印／印章」後會展開設定：文字（留空就不蓋）、樣式（置中單一／平鋪佈滿）、顏色、字級、透明度、旋轉角度、頁面範圍（例如 1-3,5，留空＝全部）。浮水印畫在最上層，疊上去的字仍然可以搜尋與複製。
    • 寫入書籤：勾選「🔖 寫入書籤」後，輸出的 PDF 會帶有原生書籤大綱（標題與階層取自最終目錄，支援中文）。書籤與目錄頁可以分開勾選：只勾書籤就不會多出目錄頁，書籤會直接指向內容頁。
    • 先預覽再下載：點擊生成後會先開啟預覽視窗（直接顯示產出的 PDF），確認無誤再按「下載 PDF」。
    • 命名檔案：按下載時會彈出視窗讓您確認檔名，確認後瀏覽器才開始下載。

其他功能

  • 清除所有檔案：若要重新開始，可以點擊「🗑️ 清除所有檔案」按鈕（需要點擊兩次以確認）。
  • 刪除來源頁面：若某個來源檔案中有您完全不需要的頁面，可以點擊「原始 PDF 頁面」面板右上角的「🗑️ 刪除頁面」，此時面板會進入編輯模式，點擊頁面右上角的「✕」即可永久刪除該頁面。再次點擊「✓ 完成」可退出編輯模式。
